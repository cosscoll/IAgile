# IAgile — CHROME Experience v2

Site de démonstration immersif IAgile, selon la direction artistique CHROME.

**Site public :** https://cosscoll.github.io/IAgile/

## Fonctionnalités de cette version
- Sculpture 3D native WebGL avec mesh géométrique, éclairage et reflets chromés
- Rotation automatique et manipulation de l'objet à la souris ou au toucher
- Interrupteur de rendu Chrome / Hologramme
- Introduction cinématique épinglée sur trois chapitres avec transformation au défilement
- Transitions entre sections, mouvement de textes mot par mot, effets parallax, cartes à inclinaison 3D
- Catalogue de formations filtrable, fiches détaillées et sélection conservée localement
- Responsive, mode mouvement réduit, fallback lorsque WebGL n'est pas disponible

## Publication

Site statique : `index.html`, `styles.css` et `script.js`. Déploiement par GitHub Pages via `.github/workflows/deploy.yml` à chaque changement de la branche `main`.

## Important

Les trois programmes présentés sont des **exemples** pour montrer le design du futur site. Les offres définitives, tarifs, paiement, comptes et accès aux formations ne sont pas configurés. Le projet ne vend donc pas encore de formations.

Les animations WebGL peuvent nécessiter une carte graphique adaptée. Une présentation alternative est prévue si la 3D WebGL n'est pas disponible.
