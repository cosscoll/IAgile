# IAgile — CHROME

Prototype du site immersif IAgile, avec charte graphique CHROME, scène 3D interactive, catalogue de démonstration et sélection de formations.

## Déploiement

Le site est statique et peut être publié avec GitHub Pages. Dans **Settings → Pages → Build and deployment**, choisir **GitHub Actions**. Chaque push sur `main` déclenche le workflow `.github/workflows/deploy.yml`.

URL prévue : https://cosscoll.github.io/IAgile/

## Avertissements

Les trois formations affichées sont des exemples. Les prix, programmes, paiement et contacts sont à confirmer. Aucun paiement en ligne n'est configuré. La scène WebGL utilise Three.js par CDN et nécessite une connexion Internet. Le site est un prototype de démonstration.
